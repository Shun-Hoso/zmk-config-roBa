# roBa 通常版へ戻す

このZIPの `roBa_R-restore.uf2` は診断機能を含まない右側用ファームウェアです。診断版と同じキー配置・400 CPI・250 Hzの設定です。ZMK Studioが有効です。

1. 球のある右側roBaをUSBでPCに接続します。
2. 右側のリセットボタンを素早く2回押します。
3. Finderに表示される `XIAO-SENSE` または `XIAO SENSE` ドライブへ `roBa_R-restore.uf2` をコピーします。
4. ドライブが消え、再起動したら完了です。

左側の書き換え、`settings_reset`、ペアリングの削除は不要です。
